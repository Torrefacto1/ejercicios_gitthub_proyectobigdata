## Cómo revisar el trabajo

Selecciona el enlace de cada ejercicio para abrir su rama y consultar los archivos y el historial de commits correspondiente.

Las ramas se mantienen separadas intencionadamente: los ejercicios de esta práctica trabajan precisamente con ramas, commits, merges y reescritura del historial. No se han fusionado todas en una única rama.
